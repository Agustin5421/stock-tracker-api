# US-024 — Iniciar sesión desde mobile

**Como** inversor,  
**quiero** iniciar sesión desde la app mobile,  
**para** acceder a mi información desde el celular.

## Criterios de aceptación
- El usuario puede ingresar mail y contraseña desde mobile.
- El sistema permite el acceso con credenciales válidas.
- El sistema rechaza credenciales inválidas.
- Luego de iniciar sesión, el usuario accede a las funcionalidades mobile disponibles.

# US-025 — Consultar portfolio desde mobile

**Como** inversor,  
**quiero** consultar mi portfolio desde mobile,  
**para** revisar mis inversiones desde el celular.

## Criterios de aceptación
- El usuario puede ver sus posiciones desde mobile.
- El usuario puede ver el valor actual de su portfolio.
- El usuario puede ver ganancia o pérdida por posición.
- El sistema muestra la fecha de última actualización de precios.

# US-026 — Registrar operaciones desde mobile

**Como** inversor,  
**quiero** registrar compras y ventas desde mobile,  
**para** actualizar mi portfolio desde el celular.

## Criterios de aceptación
- El usuario puede registrar una compra desde mobile.
- El usuario puede registrar una venta desde mobile.
- Las operaciones usan el último precio almacenado.
- El sistema valida que no se venda más cantidad que la disponible.

# US-027 — Buscar empresas desde mobile

**Como** inversor,  
**quiero** buscar empresas desde mobile,  
**para** analizar compañías desde el celular.

## Criterios de aceptación
- El usuario puede buscar por nombre o ticker desde mobile.
- El sistema muestra resultados de búsqueda.
- El usuario puede acceder al detalle financiero de una empresa desde mobile.

# US-028 — Consultar watchlist desde mobile

**Como** inversor,  
**quiero** consultar mi watchlist desde mobile,  
**para** revisar las empresas que estoy siguiendo desde el celular.

## Criterios de aceptación
- El usuario puede ver su watchlist desde mobile.
- El usuario puede acceder al detalle de una empresa de la watchlist.
- El usuario puede eliminar una empresa de la watchlist desde mobile.
