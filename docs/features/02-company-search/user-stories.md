# US-004 — Buscar empresa por nombre o ticker

Como inversor, quiero buscar empresas por nombre o ticker para encontrar compañías que pueda analizar.

## Criterios de aceptación

- El usuario puede ingresar un nombre o ticker.
- El sistema consulta la fuente de datos correspondiente de SEC EDGAR.
- El sistema muestra empresas coincidentes con la búsqueda.
- Cada resultado muestra al menos el nombre de empresa y el ticker.
- Si no hay resultados, el sistema informa que no se encontraron coincidencias.
